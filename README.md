# Vila do Bitcoin 🏘️₿

Jogo educativo web para ensinar Bitcoin para crianças, construído com Spring Boot + Thymeleaf + HTMX.

## Stack

| Camada | Tecnologia |
|---|---|
| Backend | Spring Boot 3.2 + Kotlin |
| Templates | Thymeleaf  |
| Interatividade | HTMX  |
| Banco de dados | H2  |

---


Acesse: https://vila-do-bitcoin.onrender.com/
